Which star slows the meeting-to-task run as the team grows?

Once a minute, EXO takes one finished meeting and turns its action lines into rows on the shared task Sheet. Each star is one step of that run, in order. A star's glow grows with its share of the run's time. Change the team size and watch which step takes over.

What is real. The steps, their order, the file and line references, the loops and the limits are read from EXO's source at commit 5362780. No EXO code was run.

What is measured. Copies of EXO's matching functions run on made-up task titles in this container: about 4.9 µs to hash one source identity (sourceActionIdentity), 1 µs to build one task's comparison wording (taskComparison) and 8.2 µs for one title comparison (similarAutomaticTask). The copies use made-up titles, so EXO's real numbers may differ.

What is assumed. Each person has 10 open tasks and archives 40 a year, and a third of tasks came from a meeting. The meeting has 20 action lines; 12 get past the early checks and 8 are added. Unit costs: 5 ms per database query, 120 ms per Google file check, 600 ms to read the notes, 6 s for the Sonnet call, 350 ms per Sheet read, 900 ms to write and read back the batch. Steps are added one after another within one cron run. The 15-minute wait for notes to settle is not counted.
